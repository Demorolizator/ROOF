# Как получить EXE без установки Python на ваш ПК

Вариант GitHub Actions (на вашем компьютере ничего устанавливать не нужно):

1. Откройте github.com и создайте новый пустой репозиторий.
2. Загрузите **содержимое** папки `RoofStudio_v0.5` в корень репозитория, включая скрытую папку `.github/workflows`.
3. Откройте **Actions** → **Build standalone Windows EXE** → **Run workflow**.
4. После успешной сборки откройте завершившийся запуск и скачайте **RoofStudio_v0.5_Windows_x64** из раздела **Artifacts**.
5. Распакуйте ZIP с артефактом, внутри будет `RoofStudio_v0.5.exe`.

Программа собирается на Windows-сервере GitHub. Python и зависимости входят в исполняемый файл PyInstaller `--onefile`, поэтому Python на целевом компьютере не нужен.

Важно: в этом архиве **пока нет готового EXE**. Наличие `.github/workflows/build-windows-exe.yml` лишь позволяет запустить сборку на GitHub. Сам EXE нужно получить после её успешного завершения. Запуск GUI и корректность всех функций на настоящей Windows ещё требуется проверить. Репозиторий можно сделать приватным; GitHub может требовать настройки/доступность Actions для учётной записи.
