# RoofStudio v0.5 — рабочий настольный прототип

Приложение написано на Python/Tkinter и запускается на Windows с установленным Python 3.10+. Это не HTML.

## Реализовано
- Интерфейс с верхней лентой, деревом проекта, центральной схемой и боковой панелью параметров.
- Вкладки **Геометрия**, **Стропильная система**, **Обрешётка**, **Элементы кровли**, **Ведомости**, **Документация**. В последней пока заглушка.
- Пересчёт площадей вальмовой кровли с независимыми длинами бокового и торцевого скатов и проверками геометрии. Длины обоих скатов считаются до кромки карниза; карнизный свес добавляется к габаритам дома.
- Размещение элементов: шахта, слуховое окно, фановый стояк, водосточная воронка, ограждение. Для добавления выберите инструмент и щёлкните по плану; для перемещения зажмите и перетащите объект. Можно удалить выделенный объект.
- Предварительная схема основных стропил и рядов обрешётки. Не является конструктивным расчётом.
- Таблица предварительных объёмов; сохранение и загрузка JSON; экспорт CSV.
- DXF (редактируемые контуры, рёбра, конёк, условные обозначения объектов в пространстве модели, мм, 1:1). Для DXF нужен Python-пакет `ezdxf`.

## Запуск и получение EXE
1. Установите Python 3.10+ (для Windows установщик с python.org, опция Add Python to PATH).
2. Запустите `Запустить_Windows.bat` или выполните `pip install -r requirements.txt` и `python roofstudio.py`.
3. Чтобы получить самостоятельный EXE, запустите на Windows `Собрать_EXE_Windows.bat`. После установки PyInstaller готовый файл окажется в `dist/RoofStudio_v0.5.exe`. Для запуска на целевом ПК Python уже не нужен.

**В этом пакете EXE не приложен:** текущая среда Linux не позволяет проверить и собрать нативный Windows EXE. Не переименовывайте Python-файл в EXE.

## Ограничения
- DWG и PDF пока выдают заглушку «Раздел будет добавлен позже»; DXF можно открыть в AutoCAD 2021 и сохранить как DWG.
- Общая крыша рассматривается как прямоугольная симметричная в плане вальма с горизонтальным коньком. Составные крыши ещё не реализованы.
- Стропильный план и обрешётка показаны упрощённо; не выполняются проверки несущей способности, нормативных расстояний, усилений, примыканий, крепления и вычеты по отверстиям.
- DXF не включает полноценные размеры AutoCAD, листы, рамку, штамп и спецификации — это следующая версия.
- Формулы расчёта предполагают перпендикулярные карнизам наклонные длины скатов; вводимые размеры должны быть геометрически согласованы.
